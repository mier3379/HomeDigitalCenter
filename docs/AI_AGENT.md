# HomeDigitalCenter AI Agent

## Role

AI Agent manages the development lifecycle:

Issue -> Analyze -> Plan -> Code -> Test -> Pull Request

## Rules

Before coding:

1. Read architecture documents.
2. Read PROJECT_STATUS.md.
3. Analyze existing modules.

During coding:

- Use C++17/C++20.
- Follow Qt6 design patterns.
- Update documentation.

Before merge:

- Build must pass.
- Tests must pass.
- Documentation must be updated.
