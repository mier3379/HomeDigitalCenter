# HomeDigitalCenter 项目自主开发规划

## 项目目标

HomeDigitalCenter 是基于 Qt C++ 的本地家庭数字中心平台，将 Jellyfin、阅读、播放器及本地媒体能力整合为统一桌面 EXE 应用。

## 当前架构方向

```
HomeDigitalCenter
├── app          # 主程序入口与 Qt UI
├── core         # 核心服务框架
├── modules      # 功能模块插件
├── docs         # 项目文档
└── CMakeLists.txt
```

## 第二阶段：家庭数字中心功能

### 媒体中心

- 集成 Jellyfin 服务管理
- 集成 jellyfin-ffmpeg 转码能力
- 本地媒体库扫描
- 视频播放入口

### 阅读中心

- 整合 Book-readest 项目能力
- 支持电子书管理
- 阅读进度同步

### 音乐中心

- 整合 homeAPlayer 能力
- 本地音乐播放
- 播放列表管理

## 第三阶段：桌面 EXE 产品化

- Windows 单文件安装包

- 用户配置备份
- 开机启动
- 系统托盘服务

## 开发原则

1. Qt C++ 原生实现
2. 模块独立，可替换升级
3. 本地优先，保护用户数据
4. CMake 跨平台构建
5. 持续提交可运行版本
